```release-note:improvement
client: Added the `client.selinux.label_task_sockets` option to create the Consul and Task API sockets with the container SELinux type for tasks using image-isolated drivers such as Docker, podman and containerd, so SELinux-confined tasks can use them without `label=disable`. The node attribute `nomad.selinux.label_task_sockets` is set while labeling is active, and the option is applied on configuration reload
```
